# Show and Tell

Show off items, inventories and ender chests in chat. Type `[item]`, `[inv]`, `[ender]` or `[armor]` and other players can hover for a tooltip or click to open a preview.

Fabric and NeoForge, Minecraft 26.1 to 26.3. Built with [Stonecutter](https://stonecutter.kikugie.dev/).

Icons from [pixelarticons](https://github.com/halfmage/pixelarticons) (MIT).
